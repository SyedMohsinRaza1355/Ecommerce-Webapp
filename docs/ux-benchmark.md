# UX and feature benchmark (researched 2026-11-22)

Sources: Baymard Institute (checkout, product page, cart audits, 2025-2026), Nielsen Norman Group (product pages), Toast and DoorDash (restaurant ordering), Wave Grocery / Mercatus / Zopping (grocery), fashion-commerce feature guides, Shopify and WooCommerce launch checklists.

Legend: DONE = we have it. BUILT-NOW = added in this round. NEEDS-INPUT = needs an account, key or decision from the owner.
