# DEC-03 Operator vs self-service provisioning

- Status: Proposed default (awaiting owner confirmation)
- Owner/date: Project owner, 2026-11-18
- SRS: DEC-03, ADD-001, ST-01

## Context
SRS allows both.

## Decision
Operator-created stores first (Phase 2). Paid self-service after the payment work in Phase 4; nothing is provisioned before a verified payment event.

## Consequences
Self-service is delayed until payments are proven.
